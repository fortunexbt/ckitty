  | sh -s -- --prefix "$HOME/.local"

Or build it where it stands.

git clone https://github.com/fortunexbt/ckitty.git
cd ckitty && make && ./ckitty

How the page runs the real thing

src/ckitty_core.c composes every frame into a character grid and never touches a terminal library. The native app and this page both call it, so the cat you see here is the cat you install.

src/web_curses.c stands in for the dozen ncurses calls that src/ckitty.c makes. It flushes the grid as ANSI into the terminal above and hands getch() to the browser event loop. Nothing was ported to JavaScript, and the native build still links real ncurses.

Frames are deterministic. ckitty --dump --seed 123 sit --frame 0 prints the same art every run, which is what the test suite and the README banner rely on.
