## File Descriptions

### Core Source Files

- **src/ckitty.c**: ncurses front-end (input loop + rendering to terminal)
- **src/ckitty_core.c**: deterministic procedural generation + canvas primitives
- **src/ckitty_core.h**: exported core types/constants

### Build System

- **Makefile**: Builds the single `ckitty` binary, runs tests/sanitizers, creates the demo, and installs/uninstalls
- **install.sh**: Runs verification and installs to an explicit prefix without invoking sudo

### Documentation

- **README.md**: Main project documentation with features, installation, and usage
- **CONTRIBUTING.md**: Guidelines for contributors
- **EXAMPLES.md**: Usage examples and gallery
- **assets/**: Checked-in README artwork; regenerate the GIF with `make demo`
- **LICENSE**: GPL-3.0 license text

### CI/CD

- **.github/workflows/build.yml**: GitHub Actions workflow for building and testing on multiple platforms

## Build Artifacts

These are generated by `make` and are ignored by git:

- `ckitty`
- `ckitty_test`
- `src/*.o` and `tests/*.o`
